The measured plan that [`docs/GAMEPLAY-RATINGS.md`](../../GAMEPLAY-RATINGS.md) implemented (with the final numbers and tests). Measurements came from throwaway fixed-seed simulation harnesses run with `npx vite-node`; they were not committed. Line numbers refer to the code before that change.

Contested shots too forgiving (45-rated heavy-contest 3 makes 37%). STR inverted in NBA contact (engine.ts:936-944) and NFL truck/stiff-arm/spin (engine.ts:999-1003; AI prefers weaker moves).
